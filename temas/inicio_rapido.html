Primeros pasos

Guía de inicio rápido

Pasos necesarios antes de la primera sesión de captura. Seguir este orden garantiza que el sistema quede correctamente configurado.

importante

Esta guía debe seguirse completamente antes de iniciar la primera sesión de captura. Si se omite la configuración inicial del receptor GNSS, el sistema operará con los valores de fábrica — incluyendo una frecuencia de actualización de 1 Hz en lugar de los 5 Hz recomendados.

Paso 1 — Preparar la microSD

Grabar la imagen preconfigurada en la microSD y agregar las credenciales de la red WiFi. Consultar la guía Conexión WiFi y SSH para el procedimiento completo.

Paso 2 — Configurar la sincronización

Crear el proyecto en Google Cloud, generar el token OAuth y copiarlo a la Raspberry Pi. Consultar la guía Sincronización con Google Drive para el procedimiento completo.

Paso 3 — Configuración inicial del sistema

Con el interruptor en modo configuración (posición central), encender el dispositivo y conectarse por SSH:

bash
ssh adq@192.168.X.XXX

Activar el ambiente virtual y ejecutar el script de configuración:

bash
cd /home/adq/proyecto-gnss
source env_librerias_gnss/bin/activate
python3 configurar_sistema.py

En el menú principal seleccionar la opción 3 — Configurar sensor GNSS y dentro de ese submenú seleccionar 5 — Configuración inicial recomendada. Esta secuencia realiza automáticamente:

Secuencia de configuración inicial

PasoAcciónResultado
1Cold startBorra configuración previa del receptor
2Modo AutomotiveOptimizado para vehículos de pasajeros
3Frecuencia 5 HzUna posición cada 200 ms
4Optimizar mensajes NMEASolo GGA y RMC — reduce tráfico en el bus

Al completarse, verificar que el receptor responde con el mensaje:

Configuración inicial completada. El sistema está listo para iniciar sesiones de captura.

Paso 4 — Verificar la configuración

Antes de cerrar la sesión SSH, verificar que el archivo config.json contiene los valores correctos:

bash
cat /home/adq/proyecto-gnss/config.json

El resultado debe ser similar a:

json
{
  "gnss_mode": 4,
  "gnss_mode_name": "Automotive",
  "gnss_rate_hz": 5,
  "imu_rate_hz": 100,
  "imu_range_g": 8,
  "baro_rate_hz": 5
}
valores por defecto

Si imu_rate_hz, imu_range_g o baro_rate_hz no aparecen en el archivo, el sistema usará los valores por defecto (100 Hz, 8g y 5 Hz respectivamente) al iniciar la adquisición. Solo la configuración del GNSS requiere ejecutarse explícitamente.

Paso 5 — Primera sesión de captura

Apagar el dispositivo con el botón físico. Cambiar el interruptor a la posición de captura (izquierda) y encender nuevamente.

El LED parpadeará lentamente (1 Hz) indicando que la adquisición está en curso. El sistema capturará datos de los tres sensores de forma autónoma hasta que se apague el dispositivo.

Estados del LED

LEDModoEstado
Parpadeo lento (1 Hz)CapturaAdquisición en curso
Parpadeo rápido (5 Hz)SincronizaciónSubiendo archivos a Google Drive
LED fijoSincronizaciónSincronización completada
LED fijoConfiguraciónEsperando conexión SSH

Paso 6 — Primera sincronización

Al terminar la sesión de captura, apagar el dispositivo, cambiar el interruptor a la posición de sincronización (derecha) y encender nuevamente.

El sistema se conectará automáticamente a la red WiFi y subirá todos los archivos pendientes a Google Drive. Al completarse, el LED quedará fijo. En ese momento el dispositivo puede apagarse.
