Configuración del sistema

Conexión WiFi y SSH

Cómo preparar la Raspberry Pi para conectarse a la red WiFi y acceder por SSH desde cualquier sistema operativo.

Requisitos previos

  • Tarjeta microSD (mínimo 32 GB — recomendado Samsung o SanDisk Endurance)
  • Red WiFi disponible (nombre y contraseña)
  • Acceso al panel de administración del router
  • Raspberry Pi 5 (4 GB u 8 GB)
compatibilidad

La imagen preconfigurada fue creada y probada exclusivamente para la Raspberry Pi 5. No es compatible con modelos anteriores (Raspberry Pi 4, 3, B+, etc.) debido a diferencias en el chip de procesamiento y las interfaces de hardware.

Paso 1 — Grabar la imagen en la microSD

Descarga la imagen preconfigurada del repositorio del proyecto. La imagen incluye el sistema operativo, las librerías de Python, los scripts de adquisición y todas las configuraciones de hardware (GPIO, I²C, UART). Solo es necesario agregar las credenciales WiFi.

Graba la imagen con el Raspberry Pi Imager:

  1. Abre el Raspberry Pi Imager
  2. En Operating System selecciona Use custom
  3. Elige el archivo .img.xz descargado
  4. Se selecciona la microSD en Storage
  5. Haz clic en Next — cuando pregunte si deseas aplicar configuración personalizada, selecciona No — la imagen ya viene preconfigurada

Paso 2 — Agregar la red WiFi

La única configuración necesaria es agregar las credenciales de la red WiFi. Este paso varía según el sistema operativo del equipo utilizado.

En Linux

Se inserta la microSD en la PC. Se verifica que fue detectada:

bash
lsblk
# Busca el dispositivo con dos particiones: bootfs y rootfs
nota

En los comandos siguientes, se reemplaza TU_USUARIO con el nombre del usuario en Linux. Puede verificarse con:

bash
whoami
múltiples redes

Se debe crear un archivo independiente por cada red WiFi que se desee agregar. El nombre del archivo puede ser cualquiera, pero por claridad se recomienda usar el nombre de la red. Por ejemplo: IZZI-628E.nmconnection, MI_RED_CASA.nmconnection. La Raspberry Pi intentará conectarse automáticamente a cualquiera de las redes configuradas que estén disponibles.

Se crea el archivo de configuración de red:

bash
sudo nano /media/TU_USUARIO/rootfs/etc/NetworkManager/system-connections/MI_RED.nmconnection

Se escribe el siguiente contenido — sustituyendo NOMBRE_RED y CONTRASEÑA con los datos de la red:

ini
[connection]
id=NOMBRE_RED
type=wifi
autoconnect=true

[wifi]
mode=infrastructure
ssid=NOMBRE_RED

[wifi-security]
auth-alg=open
key-mgmt=wpa-psk
psk=CONTRASEÑA

[ipv4]
method=auto

[ipv6]
method=auto

Se guarda con Ctrl+O, Enter, Ctrl+X. Ajusta los permisos — NetworkManager requiere que estos archivos solo sean legibles por root:

bash
sudo chmod 600 /media/TU_USUARIO/rootfs/etc/NetworkManager/system-connections/MI_RED.nmconnection

Se desmonta la microSD de forma segura:

bash
sudo umount /media/TU_USUARIO/bootfs
sudo umount /media/TU_USUARIO/rootfs

En Windows

En Windows el sistema de archivos ext4 de la Raspberry Pi no es legible nativamente. La alternativa es conectar la Raspberry Pi por cable Ethernet al router, acceder por SSH y configurar el WiFi desde adentro del sistema.

  1. Se inserta la microSD en la Raspberry Pi y conecta el cable Ethernet al router
  2. Se se conecta la alimentación y espera 60 segundos
  3. Se accede al panel de administración del router y se busca la sección de dispositivos conectados para encontrar la IP asignada a la Raspberry Pi
  4. Conéctate por SSH desde PowerShell:
powershell
ssh adq@192.168.X.XXX

Una vez dentro, configura el WiFi:

bash
sudo nmcli device wifi connect "NOMBRE_RED" password "CONTRASEÑA"

Verifica que la conexión fue exitosa:

bash
ping -c 4 google.com

Se desconecta el cable Ethernet — la Raspberry Pi se reconectará automáticamente por WiFi.

Paso 3 — Encender y conectarse por SSH

Se inserta la microSD en la Raspberry Pi y se conecta la alimentación. Se espera aproximadamente 60 segundos.

Encontrar la dirección IP

Desde la PC, se identifica el rango de la red:

bash
ip route   # Linux / macOS

Se busca la línea que contenga scope link y cuya interfaz (dev) empiece con w (WiFi) o e (Ethernet). Se descartan líneas con interfaces como docker, br, vir o lo.

Ejemplo de salida de ip route

LíneaAcción
192.168.1.0/24 dev wlp0s20f3 scope link Usar
172.17.0.0/16 dev docker0 scope link Descartar

Las direcciones mostradas son de ejemplo — deben sustituirse por las que resulten del comando ip route en el equipo utilizado.

Se escanea la red usando el rango identificado en el paso anterior:

bash
# Linux / macOS — sustituir 192.168.1 por el rango obtenido con ip route
sudo nmap -sn 192.168.1.0/24

# Windows — sustituir 192.168.1 por el rango obtenido con el panel del router
nmap -sn 192.168.1.0/24

La Raspberry Pi aparecerá con MAC que comienza con D8:3A:DD — prefijo de la Raspberry Pi Foundation.

Conectarse

bash
# Linux / macOS / PowerShell Windows 10+
# Sustituir 192.168.1.XXX por la IP identificada en el escaneo
ssh adq@192.168.1.XXX

La primera vez el sistema pedirá confirmar la autenticidad del host — se se escribe yes y se se presiona Enter. Si la conexión fue exitosa se mostrará:

adq@rpi-gnss:~ $

En Windows también se puede usar PuTTY como cliente SSH gráfico — se se ingresa la IP en el campo Host Name y se selecciona SSH como tipo de conexión.

Paso 4 — Fijar la dirección IP (recomendado)

Por defecto el router asigna una dirección IP diferente cada vez que la Raspberry Pi se conecta. Para evitar tener que buscarla en cada ocasión, se se configura una reserva de DHCP en el router.

Se accede al panel de administración del router y se se busca la sección de reserva de DHCP o asignación estática de IP. Se registra la dirección MAC de la Raspberry Pi junto con la IP que se desea asignar de forma permanente.

Se consulta la dirección MAC con:

bash
ip link show wlan0
# Se busca la línea "link/ether XX:XX:XX:XX:XX:XX"
modo sincronización

Una vez que la dirección IP esté fija y la red WiFi configurada, el sistema subirá los archivos automáticamente en cuanto se seleccione el modo sincronización en el interruptor y se encienda el dispositivo — sin ninguna intervención adicional. Garantizar la conexión WiFi y fijar la dirección IP son la única configuración que debe realizarse para que la transferencia de datos funcione de forma autónoma.
